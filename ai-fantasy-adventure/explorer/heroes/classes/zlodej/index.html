Character class

Rogue

Quiet, agile, and ready for locks and traps.

Rogues excel in Agility and Luck. Ordinary sneaking succeeds automatically, and their tools open paths others cannot.

Stealth, locks, traps, precise attacks, and clever solutions.

Class ability

Soft Steps

For ordinary sneaking, Vaelor assumes success. A roll is needed only for an exceptional obstacle; this cannot make hiding possible where it is objectively impossible.
