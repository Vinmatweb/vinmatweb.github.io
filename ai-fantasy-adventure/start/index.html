How to start playing

AI Fantasy Adventure is designed so that neither parents nor children need to know Dungeons & Dragons or any other RPG system.

1234✦
For the full game, upload all four documents.

The Manual sets out the general rules, while the three catalogues provide the exact values. Vaelor uses them together as one system.

1

Download the four documents

On a phone, download them individually without unzipping. On a computer, you can also use the optional ZIP containing all files.

2

Open a new AI chat

Start a new chat in an AI tool that accepts file uploads. For the best continuity, use one chat for each campaign.

3

Upload all the documents

Wait until the Manual, Bestiary, Magic, and Equipment files have loaded. If your chat limits the number of files, upload them one at a time before starting the game.

4

Write an opening prompt

Mention the number of players, their approximate ages, and optionally the game’s length or tone. Vaelor will ask only for any details it still needs.

“We’d like to start a new adventure for two players aged 7 and 9.”
5

Create your heroes and play

Vaelor recommends a race and class, calculates attributes and Health, and begins the first scene. Players simply describe what they want to do.

For a virtual roll, all you need is a number from 1 to 6.

Before each roll, Vaelor secretly shuffles the outcomes. The player says just one number, and the AI reveals the actual roll and the result of the action.
